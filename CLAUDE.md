# Multfilm studio — Claude uchun

Egasi o'zbek tilida yozadi; javoblar o'zbekcha (lotin). Bu repo qisqa multfilm videolar ishlab chiqarish uchun.
- 3D uslub: `cartoon-3d-short` skilli + `tools/remotion-cartoon` (README'dagi qadamlar). 2D uslub: `cartoon-reel` skilli + `tools/cartoon-reel`.
- Ovoz faqat `voices/<nom>/script.txt` → GitHub Actions orqali (sandboxdan Edge TTS ochilmaydi).
- Qoidalar: faqat tekshirilgan faktlar (2024-yildan oldingi), transliteratsiya qilingan ismlar uchun `names` xaritasi, pul sarflanmaydi, fayllar o'chirilmaydi.
